The idea

Replace one hop, keep one interface

Claude Code normally sends every request to Anthropic. Omnirouter replaces that single hop with a local translator: it accepts an Anthropic request, rewrites it into whatever a chosen provider speaks (OpenAI, Gemini, or Anthropic itself), streams the answer back, and translates the reply — tool calls and all — back into the shape Claude Code expects.

You choose the engine by model id. A model called claude-groq-llama3 routes to Groq; claude-mistral-large to Mistral; claude-opencode-big-pickle to OpenCode Zen. The claude- prefix is required — Claude Code silently hides any model id that doesn't contain it.

Request flow

What happens to one message

On the way back, tool_calls become Anthropic tool_use blocks, and inline <think> reasoning is stripped so it never leaks into the visible answer.

What got built

The engineering story

  • FIXED

    OpenCode Zen, called directly

    The original opencode “bridge” drove opencode's agent loop and could only return plain text. It now calls OpenCode Zen's OpenAI-compatible endpoint directly — so those models support tool-use and stream like any other, with no local process to run.

  • FIXED

    OpenRouter non-streaming returned empty

    OpenRouter relays its Anthropic events as raw bytes. In stream:false mode the reconstructor ignored them, so every OpenRouter model came back blank. It now folds those raw lines back into a complete message.

  • FIXED

    Paid models masqueraded as free

    Auto-discovery pulled OpenCode Zen's whole catalog — including paid GPT-5 / Opus / Grok tiers — and tagged them all free. Discovery now surfaces only genuinely free models.

  • FIXED

    Reasoning leaked into answers

    Some models inline <think>…</think> in their output. The translator now strips it — even when a tag is split across streaming chunks — without touching ordinary text like a < b.

  • ADDED

    A heartbeat for slow models

    Big reasoning models can think silently for tens of seconds. The gateway now sends a ping during that silence so the client knows it's alive — and never kills the request. (More below.)

Keepalive

Silence isn't death

A model that hasn't sent a token in 15 seconds isn't broken — it's thinking. The streaming endpoint emits a harmless ping every KEEPALIVE_INTERVAL seconds of silence so the caller keeps waiting instead of hanging up. The real request is never cancelled. Set the interval to 0 to switch it off.

Tokens

Give reasoning room

max_tokens caps the total output — hidden thinking plus the visible reply. Set it too low and a reasoning model spends the whole budget thinking and returns nothing. The gateway imposes no limit of its own; it forwards exactly what you send. Give reasoning spawns headroom.

Free tiers share upstream pools, so a given model may return 429 one minute and answer the next. These are surfaced as clean errors, never silent blanks. A personal key lifts most limits.

Security

Keys never leave the machine

Real keys live only in .env, which is gitignored and never tracked. .env.example holds placeholders only. No key appears in any tracked file or any commit, across the whole history. The gateway binds to 127.0.0.1 and sends each key only to that provider's own API over TLS — never to a third party.

Run it

Three steps

  • Configure — copy .env.example to .env, fill in only the providers you use. Everything boots without keys; unconfigured providers just report unhealthy.
  • Start — uvicorn gateway.main:app --env-file .env --port 8787 (or ./scripts/ensure-gateway.sh).
  • Point Claude Code at it — set ANTHROPIC_BASE_URL=http://127.0.0.1:8787, open /model, pick a gateway engine.
